# Mini Projeto - Claudia Chilante

## Descrição

Mini projeto de análise e tratamento de uma base de dados de varejo, utilizando Python e Pandas.

## Pré-requisitos

Antes de começar, certifique-se de ter o Python e a biblioteca Pandas instalados em sua máquina:

```bash
pip install pandas
```

## Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Verifique se o arquivo `Base Varejo.csv` está na mesma pasta do arquivo `tratamento_dados.py`.
3. Abra o arquivo `tratamento_dados.py`.
4. Execute o arquivo pelo Visual Studio Code ou pelo terminal.

### Execução pelo terminal

No terminal, dentro da pasta do projeto, execute:

```bash
python tratamento_dados.py
```

O programa realizará o carregamento da base, tratamento dos dados, remoção de duplicatas e algumas análises dos dados.

## Tecnologias utilizadas

- Python
- Pandas
- Visual Studio Code

## Arquivos do projeto

- `Base Varejo.csv` - base de dados utilizada no projeto.
- `tratamento_dados.py` - código Python utilizado para tratamento e análise dos dados.
- `README_ClaudiaChilante_T4.md` - instruções para execução do projeto.
